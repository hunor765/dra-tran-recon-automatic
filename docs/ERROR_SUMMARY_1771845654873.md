## Primary Error

### 1. `AttributeError: 'property' object has no attribute 'desc'`

**Location**: `api/v1/endpoints/admin.py`, line 95

**Code causing error**:
```python
query = query.order_by(Job.last_run.desc()).offset(skip).limit(limit)
                        ^^^^^^^^^^^^^^^^^
```

**Root Cause**: 
- `Job.last_run` is defined as a Python `@property` in the model
- SQLAlchemy cannot use `.desc()` (SQL ordering) on Python properties
- Properties exist only in Python, not in the database

**Impact**: 
- `GET /api/v1/admin/jobs` returns **500 Internal Server Error**
- Admin jobs page is completely broken

## The Data Model Problem

### Current (Broken) Model

In `models/job.py`, `last_run` is likely defined as:

```python
class Job(Base):
    # ... other columns ...
    
    @property  # <-- THIS IS THE PROBLEM
    def last_run(self):
        # Computed property, not a database column
        return self._last_run
```

### Why This Breaks

```python
# This works - regular column
query.order_by(Job.created_at.desc())  # ✅ SQL: ORDER BY created_at DESC

# This fails - property
query.order_by(Job.last_run.desc())    # ❌ Property has no .desc() method
```

---

## Solutions

### Option 1: Change to Database Column (Recommended)

Modify `models/job.py`:

```python
# BEFORE:
@property
def last_run(self):
    return self._last_run

# AFTER:
last_run = Column(DateTime, nullable=True)  # Regular database column
```

### Option 2: Sort in Python (Not Recommended)

Remove `.order_by()` from SQL query and sort results in Python:

```python
# In admin.py
results = await db.execute(query)  # No order_by
jobs = results.scalars().all()
jobs.sort(key=lambda x: x.last_run or datetime.min, reverse=True)  # Python sort
```

### Option 3: Use a Different Column for Sorting

Change the query to sort by `created_at` or `updated_at`:

```python
# In admin.py, line 95
query = query.order_by(Job.created_at.desc()).offset(skip).limit(limit)
```
